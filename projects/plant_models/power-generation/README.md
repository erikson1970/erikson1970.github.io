The reactor pages were moved here from `projects/plant_models/` in Milestone 17.
Their old addresses (`plant_models/pwr-plant-v4/`, `-v5/`, `-v5-2/`, `rbmk-1986/`) are
redirect stubs, as is the retired `plant_models/pwr-plant-v5-1/`.

All plant values are generic, textbook-scale figures chosen for teaching, derived
from published, publicly available sources. Each page is a copy of a file developed in
the separate `Energy-Flow` working folder (see ISSUE-018).

Famous-failures to-do list: SL-1 (1961), EBR-I (1955), BORAX-I (1954), Three Mile
Island Unit 2 (1979), Windscale (1957), NRX (1952), Fermi 1 (1966), Lucens (1969),
Fukushima Daiichi (2011), Sayano–Shushenskaya (2009).
