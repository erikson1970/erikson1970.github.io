How the model works

Design point: the exact solution of ṁhcp·dTh/dx = −UA·ΔT and ṁccp·dTc/dx = +UA·ΔT with signed flows, so ΔT varies exponentially along the length. Opposite directions give counterflow, ε = (1 − e−NTU(1−Cr)) / (1 − Cr·e−NTU(1−Cr)). Same directions give parallel flow, ε = (1 − e−NTU(1+Cr)) / (1 + Cr), which can never exceed 1/(1 + Cr). Sizing mode inverts whichever formula applies.

Flow sign: positive is each stream's design direction (hot left to right, cold right to left). Negative reverses it. A stream at zero is stagnant. With no wall losses it eventually takes on the other stream's temperature and heat transfer stops.

Live behaviour: each stream is split into 200 well-mixed cells (2 L of fluid in the tube, 4 L in the annulus), with upwind advection and local exchange UA/N · (Th − Tc). The wall has no thermal mass and the fluids have constant properties, so the response time is set only by the fluid residence time. The instrument tags (TI) show these live readings, and the dashed lines show where they will settle.

Area hint: A = UA / U, using U = 1,000 W/m²·K as a typical figure for liquid-to-liquid service.
