Timeline (prototype)

One row per box in view, ordered chronologically; bar width shows the poster's own start/end dates, not yet population-weighted — see docs/VISUALIZATION.md. Six boxes have no legible start date on the source poster (ISSUES.md ISSUE-005); their bar runs to the left edge of the visible range with a dashed edge to mark that as approximate, not a real date. Diamond markers are SEAIs. Click a bar, or a box in the list below, to select it — the box list already gives full keyboard access to every box shown here, so this chart doesn't duplicate it with a hidden list of its own the way the alluvial diagram below does. Selecting a box or a succession link anywhere on the page (here, the list, or the alluvial diagram) is reflected everywhere else: the selected box's bar and the alluvial diagram's matching node both get an outline, and a selected link's two endpoint boxes are outlined here too. The year range and time compression slider below are shared with the alluvial diagram too (see docs/timescaleRequirement.md): both views place dates along the same nonlinear axis, so a year always lands at the same relative position in both.

Succession (alluvial view, prototype subset)

Ribbon width represents equal weighting for now, not literal population transfer or estimated historical scale — see docs/VISUALIZATION.md. Covers 7 hand-authored links, not the full dataset: Roman Empire → Western Roman Empire and → Byzantine Empire; Frankish Kingdom → West Francia and → East Francia; West Francia → Kingdom of France; East Francia → Holy Roman Empire; and Byzantine Empire → Ottoman Empire. Selecting a node or link here is reflected in the timeline and box list too, and vice versa — see the timeline's own note above. Node position (left-to-right) is chronological, placed on the same shared, nonlinear time scale as the timeline above — the year range and time compression slider up there apply here too.
